# MiFix LLC blog

A small Jekyll-powered blog for MiFix LLC.

## Local development

```sh
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.

Posts live in `_posts` and use standard Jekyll front matter. Site-wide settings are in `_config.yml`.

## GitHub Pages

The `main` branch deploys automatically through GitHub Actions to <https://mifix.github.io>.
